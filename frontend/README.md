# Frontend – ConManagement

Angular 18+, Tailwind CSS. Comunicare cu API .NET (JWT).

## Configurare

- **API URL**: va fi setat într-un environment (ex. `src/environments/environment.ts`) – de adăugat când conectăm la backend.
- **Tailwind**: deja inclus în `src/styles.css` și `postcss.config.js`.

## Comenzi

```bash
npm install
npm start
```

Aplicația rulează la http://localhost:4200

## Faza 1

Proiect gol cu dependențe și configurare: Angular 18, Tailwind 4, routing, HttpClient, o pagină placeholder Dashboard. Login, guards și paginile din plan vor fi adăugate în fazele următoare.
